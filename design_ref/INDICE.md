# Índice de pantallas

Cada pantalla tiene tres archivos con el mismo nombre:

- `pantallas_png/<id>.png`: cómo debe verse (referencia visual exacta).
- `pantallas_html/<id>.html`: la misma pantalla en HTML estático. Ábrelo en el navegador e inspecciona medidas, colores, radios y textos.
- `fuente_dc/<id>.dc.html`: el archivo original del lienzo de diseño, con los datos de ejemplo separados en el script.

Las notas de UX de cada pantalla están en `pantallas.json`.
