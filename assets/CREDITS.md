# Assets & Attribution

This folder contains graphical assets and placeholders for the Godot 4 MMORPG Prototype Client.

## Item Icons (`assets/icons/items/`)
- Prototype icons (`amulet1x1`, `backpack`, `dagger1x2`, `dagger2x1`, `iron1x1`, `kit1x1`, `lifepot1x1`, `manapot1x1`, `minidager1x1`, `scroll1x1`, `stone1x1`, `wood1x1`) are development placeholders created for testing inventory grid layout, slot packing, and UI rendering.
- License: Creative Commons Attribution 4.0 International (CC-BY 4.0) / Public Domain Dedication for client development.

## 3D Models & Geometry (`assets/placeholders/`, `assets/models/`)
- Procedural CSG geometries and placeholder meshes generated in Godot 4 (`generate_placeholders.gd`).
- All placeholder scenes are open-source and free to adapt.
